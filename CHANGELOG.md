# Changelog

## 0.2.0 — local reconstructed release candidate

This is a present-day reconstruction of existing implementation work, not an
original publication record. No release or Git tag has been created.
See [source provenance](HISTORY.md) for the original commit mapping.

- Preserve the original four-screen TUI, help, profiles, subscriptions and per-application mappings.
- Add transactional SQLite with recoverable legacy JSON migration and private backups.
- Add bounded multi-format imports, deduplication and shared source ownership.
- Support optional native Xray, V2Ray and sing-box with capability checks.
- Add concurrent bounded proxy tests, persistent diagnostics and measurement ranking.
- Add rotation hysteresis, cooldown, pinning and session-safe selectors.
- Add a rootless owned runtime supervisor, private IPC and bounded recovery.
- Add loopback listeners, explicit routing, native static DNS and resumable explicit-candidate scanning.
- Add authenticated local API, structured automation, private exports, completions and manual.
- Add safe code upgrades/rollback, deterministic source/zipapp builds and gated publication.
- Use portable project paths and loopback-only proxy bypass defaults.
- Exclude Windscribe experiments and internal development reports throughout reconstructed history; restrict packaged documentation to reviewed public files.
